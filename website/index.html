核心特性

为「自己定义 AI 能力」而设计的对话框架

🧩

技能即插件

skills/ 下每个目录就是一个技能，新建或修改文件夹即可增删能力，无需改框架代码。

⚙️

UI 参数自动生成

技能在 config.json 里声明参数，前端自动渲染输入控件，界面代码零改动。

🧠

长期记忆

Chroma 向量检索历史对话，跨会话回忆上下文，越聊越懂你。

📎

文档 / 图片上传

对话可结合上传的文档和图片内容回答，知识就在你手边。

💬

流式思考输出

支持带思考过程的流式输出，回答过程全程可见。

🔒

本地运行 · 隐私安全

所有数据保存在本机，不依赖云端，断网也能用。
